✦ Aster Delete Morph Target

Công cụ xóa Morph Target khỏi VRM · xử lý model ngay trên thiết bị · RAM Saver

1. Mở model VRM

Chưa có model
Chọn một file .vrm để bắt đầu.

Model được xử lý cục bộ trong trình duyệt; không tải lên máy chủ. File trên 30 MB tự động tắt 3D Preview để giảm RAM. Bản gốc không bị thay đổi.

2. Preview model

Kéo để xoay · vuốt trên điện thoại cũng được. Preview cần kết nối internet để tải thư viện 3D lần đầu.

4. Xuất VRM

Công cụ chỉnh cấu trúc GLB trực tiếp để giữ nguyên các chunk nhị phân và extension VRM. Morph Target đã xóa sẽ được gỡ khỏi các bind biểu cảm tương ứng. Hãy kiểm tra lại file xuất trong ứng dụng VRM bạn đang dùng trước khi thay thế bản gốc.
